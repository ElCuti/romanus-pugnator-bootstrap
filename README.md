# ⚔️ Romanus Pugnator — Landing Page en Bootstrap

Proyecto final desarrollado para el curso de **Bootstrap** de la academia **Mastermind**. 

El trabajo consiste en el diseño y maquetación de una página de presentación de producto para la marca ficticia **Romanus Pugnator**, enlazada con una página de contacto.

---

## 📌 Características

* 📱 **Diseño Responsivo:** Adaptado a dispositivos móviles, tablets y ordenadores.
* 🛠️ **Componentes de Bootstrap:** Uso de la cuadrícula (Grid), navegación, tarjetas y formularios.
* 🔗 **Estructura de Navegación:** Conexión entre la landing page del producto y la página de contacto.

---

## 🛠️ Tecnologías

* **HTML5**
* **CSS3**
* **Bootstrap**
